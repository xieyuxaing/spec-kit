# Spec Kit 学习 Demo

这个目录用于存放后续学习、演练和验证 SDD 流程时产生的 demo、草稿和实践记录。

约定：

- demo 只用于个人学习和实战验证，不作为官方示例或产品代码入口。
- 每个 demo 使用独立子目录，例如 `spec-kit-demo-principles/` 或 `tu-share-stock-screener-first-practice/`。
- demo 中可以保留 `.specify/`、agent 命令文件、spec、plan、tasks 等学习产物。
- 不把学习 demo 放到仓库根目录、`docs/` 官方入口或源码目录下。
- 如果 demo 只是临时验证，完成后在本目录记录结论，再决定是否保留生成文件。
